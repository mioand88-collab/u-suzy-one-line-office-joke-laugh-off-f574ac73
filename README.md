## What it does

`main.ts` writes one original one-line office joke to `/output/entry.txt`. Before writing, it validates the line against the competition gate: 1–200 characters, not only whitespace, and a single line with no newline characters.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs natively). The joke is written to `/output/entry.txt`.
